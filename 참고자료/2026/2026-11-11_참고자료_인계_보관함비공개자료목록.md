- 관련 업무: 생성형 AI 사용 시 내부자료·개인정보 관리 (11-10 조달청 평가위원 사진 업로드 사례 계기)

## 1. 한 줄 요약
보관함 md 43건 중 '비공개' 표시 6건, 표시가 없지만 내부 검토자료로 보이는 14건, 개인 휴대전화번호가 든 문서 6건을 찾았다. 이 자료들은 퇴근GO·Claude Code 작업 때 일부가 AI로 보내졌고, GitHub 비공개 저장소에도 올라가 있다.

## 2. 결론·결정 사항
1. (판단) rag md는 작업할 때 필요한 부분만 Claude로 보내졌다(퇴근GO 발췌·자료카드, Claude Code 파일 읽기, 보관 시 요약·태그). 로컬 임베딩(Ollama)과 kordoc 변환은 PC 안에서만 돌았다. 모델 학습 여부는 그 기간 claude.ai 계정의 학습 허용 설정에 달려 있다 — 이유: 처리용 전송과 학습은 다르며, 계정 설정은 사용자만 확인 가능
2. (판단) 기관 보안 관점의 핵심은 학습 여부보다 '외부 AI 서비스로 보냈는지'다 — 이유: '비공개' 표시 자료(인사청문회 답변 등)가 포함됨. 기관 생성형 AI 지침 기준으로 판단 필요
3. (결정) 개인정보(사진·연락처·개인 프로필)는 AI 지시문·보관함·결과물에 옮기지 않고 자리 표시(000-0000-0000, ○○○)로 쓴다 — 이유: 11-11 사용자 요청. 노트북 Claude Code 메모리에 규칙으로 저장함
4. (판단) 사무실 대표·직통 번호(044-…)는 업무용 공개 번호라 우선순위가 낮고, 개인 휴대전화(010-…)부터 가린다
